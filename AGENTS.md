# AGENTS.md

Цей файл — стартова орієнтація для бізнес-аналітика в репозиторії клієнтського сайту Фундації Лятошинського.

## Проєкт

Це навчальна копія публічного сайту Фундації Лятошинського: місце, де відвідувач знайомиться зі спадщиною Бориса Лятошинського, місією фундації, архівом, творчістю, дослідженнями, новинами та способами підтримки й співпраці. Сайт двомовний (українська та англійська); адреси мають префікс локалі, наприклад `/uk/archive`. Українська (`uk`) — мова за замовчуванням.

## Основні сторінки

| Маршрут | Бізнес-призначення |
| --- | --- |
| `/` | Головна: вхід на сайт, спадщина композитора і короткі переходи до ключових розділів фундації. |
| `/about-us` | Про фундацію: хто ми, місія, цілі та чим займається організація. |
| `/biography` | Життєпис Бориса Лятошинського. |
| `/artistry` | Творчість: знайомство з музичним доробком, зокрема каталогом творів. |
| `/research` | Дослідження та наукові роботи. |
| `/archive` | Каталог архівних фондів: документи, листи, афіші, рукописи та інші джерела. |
| `/archive/{fund}` | Склад одного фонду: опис фонду і перелік справ або документів у ньому. |
| `/archive/{fund}/{case}` | Картка однієї архівної справи: шифр, назва, дати, аркуші та документи для перегляду. |
| `/news` | Новини, події та згадки в медіа. |
| `/cooperation` | Співпраця: формати партнерства для партнерів, благодійників і меценатів. |
| `/support-us` | Підтримка фундації: на що йдуть внески, форма донату. У навчальній версії оплата не працює — форма демонстраційна. |
| `/war-in-ukraine` | Робота фундації під час війни в Україні та ініціативи, які вона підтримує. |
| `/contacts` | Контакти фундації (email, соцмережі) і форма пропозиції співпраці. У навчальній версії форма лише перевіряє поля — запит нікуди не надсилається й не зберігається. |
| `/privacy-policy` | Політика конфіденційності: як збирають, використовують і захищають персональні дані. |
| `/terms` | Умови користування сайтом, доступ до матеріалів і обов’язки користувача. |
| невідомий маршрут | Сторінка «не знайдено»: запропонувати перевірити адресу або повернутися на головну. |

Тексти інтерфейсу лежать у `i18n/messages/uk.json` (українська) та `i18n/messages/en.json` (англійська). Список маршрутів — у `app/shared/components/constants/routes.ts`.

## Конвенції

- Новий код пишемо на TypeScript (`.ts` / `.tsx`).
- Модулі експортуємо іменованими експортами. Файли маршрутів Next.js (`page.tsx`, `layout.tsx`, `error.tsx`) лишаються з `export default`, бо цього вимагає фреймворк.
- Українська (`uk`) — основна мова продукту і текстів. Англійська (`en`) — друга локаль; нові формулювання спочатку фіксуємо українською.

## Навчальний репозиторій

Це шаблон для воркшопу, а не бойове середовище. Окремої постійної бази немає: під час `npm run dev` і `npm run start` піднімається in-memory MongoDB, у неї заливаються демо-дані, а після зупинки процесу база зникає. Кожен новий запуск починається з чистого набору демо-даних; зміни, зроблені в інтерфейсі, між запусками не зберігаються.
